Same server, three verbs on /mcp

POST /mcp Cursor → MCP. Initialize session, then JSON-RPC: tools/list, tools/call for list_topics / get_question / check_answer.
GET /mcp MCP → Cursor. SSE stream for the same mcp-session-id — server can push while tools run.
DELETE /mcp End the session. Transport closes; entry removed from the Map inside the same process.
